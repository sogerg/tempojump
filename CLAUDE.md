## Routine Git multi-PC (bureau + portable)
Je code sur ce projet depuis deux PC différents (bureau + portable vacances). Règle d'or : **Pull en arrivant, Push en partant**.
- En **début** de session de code : rappelle-moi de faire un Pull (Sync Changes, `Ctrl+Shift+G`) avant de commencer à modifier du code.
- En **fin** de session : rappelle-moi de faire un Push (Sync Changes) avant de fermer, sinon le travail reste coincé sur cette machine et l'autre PC ne le verra jamais.
